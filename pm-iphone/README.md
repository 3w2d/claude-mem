# إدارة المشروع — تطبيق الآيفون

غلاف آيفون لبرنامج «إدارة المشروع» الذي يعمل على كمبيوتر المستخدم. لا يحتوي بيانات: يعرض واجهة البرنامج من الكمبيوتر عبر الواي فاي.

- أول فتح: «ربط بالكمبيوتر بالكاميرا» يصوّر رمز QR الظاهر على الكمبيوتر بعد «ربط جوال».
- يحفظ عنوان الكمبيوتر وجلسة الربط، ويفتح مباشرة بعدها.
- يقبل عناوين الشبكة المحلية فقط (192.168.x.x و 10.x.x.x و 172.16–31.x.x و .local).
- ملفات الفاتورة والمطالبة وPDF تُفتح في معاينة الآيفون.

البناء: `.github/workflows/pm-iphone.yml` على macOS في GitHub Actions يُنتج `PM.ipa` غير موقّع
(فرع `pm-iphone-build`). التثبيت بـ Sideloadly أو AltStore من ويندوز بحساب Apple المجاني (يُجدَّد كل 7 أيام).
